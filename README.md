# Análisis de Conservación de Especies en Antioquia con datos del 2023

## Descripción
Análisis exploratorio de 10 especies amenazadas en Antioquia,
combinando Python para análisis y visualización, y SQL para
consultas sobre los datos. Fuente: Instituto Humboldt e IUCN.

## Hallazgos principales
1. 4 especies están en peligro crítico — Rana dorada,
   Cóndor andino, Pez capitán y Loro orejiamarillo.

2. La Rana dorada es la más urgente con solo 50 individuos.
   Le siguen el Jaguar (80) y el Cóndor andino (150).

3. Los Ríos y Urabá son las regiones más críticas con
   un promedio de 200 individuos por especie.

4. Los Anfibios son el grupo más amenazado con solo
   50 individuos en promedio.

## Herramientas usadas
- Python (Google Colab)
- pandas
- matplotlib
- SQL (SQLiteOnline)

## Estructura del análisis
1. Carga y exploración del dataset
2. Análisis por estado de amenaza
3. Área protegida vs población
4. Análisis por región
5. Consultas SQL
6. Informe final con recomendaciones
